# Comiccon Adventure - Juego de Mundo Abierto

Un pequeño juego de mundo abierto ambientado en una comiccon donde puedes explorar y hablar con diferentes personajes.

## Versiones Disponibles

### 🎮 Versión 2D (`comiccon-game.html`)
Vista superior clásica con gráficos 2D en Canvas

### 🌐 Versión 3D (`comiccon-game-3d.html`) ⭐ NUEVO
Experiencia inmersiva en primera persona con gráficos 3D usando Three.js

## Características

- **Movimiento libre**: Explora el mapa completo de la comiccon
- **10 NPCs únicos**: Cada uno con su propia personalidad y diálogo
- **Sistema de colisiones**: No puedes atravesar paredes ni NPCs
- **Interacciones**: Habla con los personajes cercanos
- **Diferentes áreas**: Stands de comics, escenario, mesas de artistas y más

## Cómo jugar

### Versión 2D
1. Abre el archivo `comiccon-game.html` en tu navegador web
2. Usa las teclas **WASD** o las **flechas** para moverte
3. Acércate a los NPCs (personajes con círculos de colores)
4. Presiona **E** cuando veas el indicador para hablar con ellos
5. Presiona **E** nuevamente para cerrar el diálogo

### Versión 3D
1. Abre el archivo `comiccon-game-3d.html` en tu navegador web
2. Haz **click en la pantalla** para activar los controles
3. Usa **WASD** para moverte y el **mouse** para mirar alrededor
4. Mantén **SHIFT** para correr
5. Presiona **E** para interactuar con NPCs cercanos
6. Presiona **ESC** para liberar el cursor

## Mapa

El mapa incluye:
- 🧱 **Paredes rojas**: No puedes atravesarlas
- 🟧 **Stands naranjas**: Áreas de venta de comics y merchandising
- 🟨 **Escenario amarillo**: Área principal de eventos
- 🟦 **Mesas azules**: Áreas de trabajo de artistas
- ⬛ **Piso oscuro**: Áreas por donde puedes caminar

## Características 3D Especiales

La versión 3D incluye:
- 🎥 **Cámara en primera persona**: Experimenta la comiccon desde dentro
- 💡 **Iluminación dinámica**: Luces ambientales y sombras realistas
- 🎨 **NPCs con modelos 3D**: Personajes con cuerpo, cabeza y ojos animados
- 🏃 **Sistema de correr**: Mantén SHIFT para moverte más rápido
- 🌫️ **Niebla atmosférica**: Crea profundidad en el entorno
- 👁️ **NPCs interactivos**: Los personajes te miran cuando te acercas
- ✨ **Indicadores flotantes**: Animaciones suaves para mostrar interacciones
- 🎮 **Controles PointerLock**: Control de cámara inmersivo con el mouse

## Tecnologías

### Versión 2D
- HTML5 Canvas para renderizado 2D
- JavaScript vanilla para la lógica del juego
- CSS3 para la interfaz de usuario

### Versión 3D
- Three.js (WebGL) para gráficos 3D
- PointerLockControls para controles inmersivos
- Sistema de física y colisiones 3D
- Iluminación y sombras en tiempo real
